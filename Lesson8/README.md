# CIFAR-10 klassifikatoru (Qt)

Настольное приложение для модели из практики Модуля 5: открываете фото, и модель говорит, какой из 10 классов CIFAR-10 на нём изображён.

## 1. Сохраните модели в ноутбуке

Раздел 14 в конце ноутбука сохраняет **все** обученные модели из `trained` в папку `models/` (по файлу `.keras` на модель) и пишет `models/models.json` с названием и точностью на тесте каждой.

В Colab раскомментируйте последнюю ячейку: она упакует папку в `models.zip` и скачает её. Распакуйте архив и положите папку `models` рядом с `app.py`.

Приложение показывает модели в выпадающем списке, лучшая стоит первой и загружается при запуске. При выборе другой модели текущее фото сразу пересчитывается. Кнопка «Model seç» добавляет в список любой другой `.keras`-файл. Старый вариант с одним `cifar10_model.keras` рядом с `app.py` тоже работает.

## 2. Установите зависимости и запустите

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
python app.py
```

Нужен Python 3.10–3.12 и TensorFlow 2.16 или новее (с Keras 3, как в Colab). Для одного фото GPU не нужен, всё считается на процессоре.

## Как пользоваться

- «Şəkil seç», клик по левой области или Ctrl+O — выбрать файл.
- Перетащите фото в левую область.
- Ctrl+V — вставить картинку из буфера (например, скопированную в браузере).

Справа видно, что получает сеть на вход (фото, обрезанное по центру до квадрата и сжатое до 32×32), ответ модели и вероятности всех 10 классов.

## Что важно сказать студентам

- Подготовка фото в приложении та же, что в ноутбуке: 32×32 и деление на 255. Если подготовить иначе, модель будет ошибаться.
- Модель знает только 10 классов. Фото человека или чашки она всё равно отнесёт к одному из них — это хороший повод поговорить об ограничениях классификатора.
- CIFAR-10 — маленькие картинки с объектом по центру. На фото, где объект занимает весь кадр, модель работает заметно лучше.
